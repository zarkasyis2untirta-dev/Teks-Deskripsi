Bagian 1: Definisi & Tujuan

1. Definisi Teks Deskripsi

A Pengertian

Teks deskripsi adalah jenis teks atau wacana yang bertujuan untuk menggambarkan, melukiskan, atau memaparkan suatu objek, tempat, suasana, atau peristiwa secara terperinci kepada pembaca.

B Tujuan Utama

Tujuan utama dari wacana deskriptif adalah objektifikasi persepsi, yaitu memindahkan pengalaman spasial, visual, auditif, maupun taktil dari penulis ke dalam imajinasi pembaca secara presisi, sehingga pembaca seolah-olah mengalami interaksi langsung dengan objek tersebut.

Bagian 2: Klasifikasi Teks

2. Jenis-Jenis Teks Deskripsi

A. Berdasarkan Objek Penggambaran

Deskripsi Spasial (Ruang dan Tempat)
"Di sudut kiri ruang tamu berdiri sebuah sofa panjang berwarna abu-abu, tepat menghadap ke arah meja televisi berukuran sedang yang menempel di dinding utara."
Deskripsi Orang (Karakter/Fisik)
"Pak Harun memiliki postur tubuh yang tinggi tegap dengan rambut putih yang mulai menipis di bagian pelipis, serta sorot mata tajam yang selalu menyiratkan ketegasan saat ia mengajar."
Deskripsi Waktu
"Suasana pelabuhan pada pukul lima pagi tampak remang-remang diselimuti kabut tipis, sementara lampu-lampu kapal masih menyala terang di tengah permukaan air laut yang tenang."
Deskripsi Objek/Benda
"Kucing berbulu lebat itu memiliki warna oranye keemasan dengan mata bulat berwarna hijau terang dan ekor panjang yang selalu bergerak-gerak lincah."

B. Berdasarkan Tingkat Subjektivitas

1. Deskripsi Objektif (Eksplanatori)

"Gedung perpustakaan tersebut memiliki panjang 40 meter, lebar 20 meter, serta dibangun menggunakan fondasi beton bertulang dengan dinding eksterior berlapis kaca temper."

2. Deskripsi Subjektif (Afektif)

"Puncak gunung itu berdiri dengan angkuh dan megah, memancarkan pesona magis yang sanggup membuat siapa pun merasa kecil di hadapan keindahan alam semesta."

C. Berdasarkan Keterikatan Teks

1. Deskripsi Berdiri Sendiri

"Pantai Kuta Mandalika membentang luas dengan hamparan pasir putih yang bertekstur lembut menyerupai merica, berpadu sempurna dengan air lautnya yang jernih berwarna kebiruan."

2. Deskripsi Terikat (Bagian Teks Lain)

"Malam itu, angin dingin berhembus kencang menembus dinding kayu gubuk reot tempat Siti duduk termenung memandangi nyala lampu pelita yang hampir padam."

Bagian 3: Anatomi Struktur

3. Konstruksi Struktur Teks Deskripsi

1. IDENTIFIKASI
Elemen Penentu / Orientasi

Memuat penetapan identitas objek, baik berupa nama, letak geografis, sejarah singkat, maupun pengelompokan umum untuk memberikan batas konteks pembaca.

2. DESKRIPSI BAGIAN
Elemen Elaborasi

Inti teks yang memecah objek utama menjadi sub-komponent. Pemanfaatan pencerapan indra secara maksimal untuk merinci ciri-ciri fisik maupun nonfisik.

3. SIMPULAN / KESAN
Elemen Penutup

Berisi pandangan menyeluruh, penekanan nilai estetika, atau dampak emosional objek terhadap penulis/pembaca.

Contoh Teks Bedah Struktur: Kawasan Konservasi Mangrove Mangunharjo

[IDENTIFIKASI]

Kawasan Konservasi Mangrove Mangunharjo merupakan area hutan bakau seluas 50 hektar yang terletak di pesisir utara Semarang. Area ini berfungsi sebagai benteng ekologis alami yang melindungi garis pantai dari abrasi sekaligus menjadi habitat beragam biota laut dan burung migran.

[DESKRIPSI BAGIAN]

Mengandalkan ekosistem khas pesisir, kawasan ini didominasi oleh spesies bakau Rhizophora mucronata yang memiliki akar tunjang mencengkeram erat ke dalam lumpur hitam pekat. Jalur penjelajahan berupa jembatan kayu ulin selebar 1,5 meter terbentang membelah rimbunnya dedaunan hijau tua yang saling bertumpukan. Udara di dalam kawasan terasa lembap dengan aroma khas garam dan sedimen tanah asin. Di sepanjang jalur, sayup-sayup terdengar kepakan sayap burung blekok serta derik serangga bakau yang saling bersahutan di antara selaksa dahan. Pada jarak setiap 100 meter, terdapat gardu pandang kayu beratap jerami yang menyajikan pemandangan terbuka ke arah Laut Jawa yang membiru di horizon jauh.

[SIMPULAN]

Keberadaan Kawasan Konservasi Mangrove Mangunharjo tidak hanya menjadi peredam gempuran gelombang laut, tetapi juga menyajikan keharmonisan antara vegetasi pesisir dan satwa liar yang patut dijaga kelestariannya.

Panduan Integration Google Apps Script (GAS)

Salin kode di bawah ini ke Google Apps Script Spreadsheet Anda.

  1. Buka Google Spreadsheet Baru → Klik menu Ekstensi (Extensions) → Apps Script.
  2. Hapus semua kode lama, lalu tempelkan (paste) kode Apps Script lengkap di bawah ini.
  3. Klik Terapkan (Deploy) → Terapkan Sebagai Web App (New Deployment).
  4. Setel "Who has access" menjadi Anyone (Siapa Saja).
  5. Salin URL Web App dan tempel pada input URL di bawah ini.
// ==== KODE GOOGLE APPS SCRIPT (GAS) DATABASE CRUD ====
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var result = [];
  
  if (data.length > 1) {
    var headers = data[0];
    for (var i = 1; i < data.length; i++) {
      var row = data[i];
      result.push({
        nama: row[0],
        kelas: row[1],
        preTest: row[2],
        postTest: row[3]
      });
    }
  }
  
  return ContentService.createTextOutput(JSON.stringify({ status: "success", data: result }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Nama", "Kelas", "Nilai Pre Test", "Nilai Post Test"]);
  }
  
  var contents = JSON.parse(e.postData.contents);
  var action = contents.action;
  
  if (action === "LOGIN_OR_PRE") {
    var nama = contents.nama;
    var kelas = contents.kelas;
    var preTest = contents.preTest !== undefined ? contents.preTest : "";
    
    var data = sheet.getDataRange().getValues();
    var foundIndex = -1;
    
    for (var i = 1; i < data.length; i++) {
      if (data[i][0].toString().toLowerCase() === nama.toLowerCase() && data[i][1] === kelas) {
        foundIndex = i + 1;
        break;
      }
    }
    
    if (foundIndex !== -1) {
      if (preTest !== "") sheet.getRange(foundIndex, 3).setValue(preTest);
    } else {
      sheet.appendRow([nama, kelas, preTest, ""]);
    }
    return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
  }
  
  if (action === "POST_TEST") {
    var nama = contents.nama;
    var kelas = contents.kelas;
    var postTest = contents.postTest;
    
    var data = sheet.getDataRange().getValues();
    for (var i = 1; i < data.length; i++) {
      if (data[i][0].toString().toLowerCase() === nama.toLowerCase() && data[i][1] === kelas) {
        sheet.getRange(i + 1, 4).setValue(postTest);
        break;
      }
    }
    return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
  }
}
